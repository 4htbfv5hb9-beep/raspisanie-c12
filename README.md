# Расписание С-12

Telegram Mini App и бот личных уведомлений для учебной группы С-12.

## Личные уведомления

- `/start` — подписаться на личные уведомления;
- `/stop` — отключить уведомления;
- `/status` — проверить подписку.

Каждый студент должен самостоятельно открыть бота и нажать Start или отправить `/start`, иначе Telegram не разрешит присылать ему личные сообщения.

## Автоматическая проверка замен

Бот загружает страницу [замен колледжа](https://bask-rb.ru/замены), находит блок группы С-12 и сравнивает его с предыдущей успешной проверкой. Проверка выполняется при запуске и затем каждые **90 минут (1 час 30 минут)**. Если блок изменился, активным подписчикам отправляется уведомление.

Первая успешная проверка только сохраняет исходное состояние страницы и не рассылает уже опубликованные сведения. Для хранения подписчиков и состояния проверки нужен постоянный диск.

## Переменные окружения

- `BOT_TOKEN` — токен Telegram-бота из BotFather (секрет, не публиковать);
- `DATABASE_PATH` — путь к SQLite-файлу, например `/data/subscribers.sqlite3`;
- `LOG_LEVEL` — уровень логирования, по умолчанию `INFO`.

## Запуск

Python 3.12+:

```bash
pip install -r requirements.txt
BOT_TOKEN="..." DATABASE_PATH="data/subscribers.sqlite3" python bot.py
```

Или используйте Dockerfile.

**Важно:** не запускайте два процесса long polling с одним токеном одновременно. Перед запуском этой версии остановите любой старый экземпляр бота. На бесплатном хостинге постоянное хранение SQLite может быть недоступно; без него список подписчиков и сохранённый снимок замен могут потеряться после перезапуска.
