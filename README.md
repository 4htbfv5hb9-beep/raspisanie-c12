# Расписание С-12

Telegram Mini App и бот личных уведомлений для учебной группы С-12.

## Личные уведомления

- `/start` — подписаться на личные уведомления;
- `/stop` — отключить уведомления;
- `/status` — проверить подписку.

Каждый студент должен самостоятельно открыть бота и нажать Start или отправить `/start`, иначе Telegram не разрешит присылать ему личные сообщения.

## Автоматическая проверка замен через GitHub Actions

- GitHub Actions запускает обработчик примерно каждые 5 минут, чтобы получать команды Telegram.
- Страница замен колледжа проверяется не чаще одного раза в 90 минут.
- Если раздел С-12 изменился, активным подписчикам отправляется сообщение.
- Первая успешная проверка сохраняет исходное состояние и не рассылает старые записи.
- Подписчики, смещение Telegram Updates и снимок расписания сохраняются в зашифрованном файле `data/state.enc`. Ключ шифрования выводится из `BOT_TOKEN`; сам токен хранится только в GitHub Secrets.

### Однократная настройка

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Secrets and variables → Actions**.
3. Нажмите **New repository secret**.
4. Имя секрета: `BOT_TOKEN`.
5. Значение: токен из BotFather. Не публикуйте его и не отправляйте в чат.
6. После добавления секрета объедините pull request с GitHub Actions workflow в ветку `main`.

### Важно

- Запуски по расписанию могут задерживаться; это не гарантия точной проверки каждые 5 минут.
- GitHub Actions для публичных репозиториев использует стандартные runners бесплатно; для приватных репозиториев действуют лимиты плана.
- Не запускайте одновременно старый long-polling процесс из `bot.py` и GitHub Actions с тем же токеном.
- После первого запуска откройте **Actions** и проверьте, что задача завершилась успешно.
- Парсер страницы нужно сверить с реальным содержимым сайта после первого запуска.
- Если изменить токен бота, зашифрованный файл состояния перестанет расшифровываться. Сначала сохраните резервную копию и перенесите состояние отдельно.

## Локальный запуск старой версии

Для локального запуска старого polling-варианта:

```bash
pip install -r requirements.txt
BOT_TOKEN="..." DATABASE_PATH="data/subscribers.sqlite3" python bot.py
```

Не запускайте локальную версию одновременно с GitHub Actions.
