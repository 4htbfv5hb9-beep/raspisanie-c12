# Расписание С-12

Telegram Mini App — расписание учебной группы С-12.

## Личные уведомления Telegram

В ветке `feature/private-notifications` добавлен отдельный Telegram-бот подписок:

- `/start` — включить личные уведомления и зарегистрировать Telegram chat ID;
- `/stop` — отключить уведомления;
- `/status` — проверить подписку.
- база подписчиков хранится в SQLite;
- функция `send_to_subscribers(application, text)` отправляет одно сообщение всем активным подписчикам и отключает недоступные чаты.

### Переменные окружения

Скопируйте значения из `.env.example` в настройки переменных окружения хостинга:

- `BOT_TOKEN` — токен бота из BotFather (секрет, не публиковать);
- `DATABASE_PATH` — путь к SQLite-файлу, например `/data/subscribers.sqlite3`.

**Важно:** для `DATABASE_PATH` используйте постоянный диск/volume хостинга. Без постоянного хранилища список подписчиков может пропасть при перезапуске или пересоздании контейнера.

### Запуск

Требуется Python 3.12+:

```bash
pip install -r requirements.txt
BOT_TOKEN="..." python bot.py
```

Или соберите контейнер через Dockerfile. Для постоянной работы нужен worker/service, который не засыпает, с подключённым постоянным диском.

### Важно перед запуском

Если этот же Telegram-токен уже используется другим процессом с long polling, остановите старый процесс перед запуском новой версии: Telegram не позволит двум polling-процессам одновременно получать обновления.

Пока автоматический сбор замен с сайта колледжа не подключён. Функция рассылки уже подготовлена, но для отправки реальных сообщений нужен источник актуальных замен и вызов `send_to_subscribers` после обнаружения нового изменения.
